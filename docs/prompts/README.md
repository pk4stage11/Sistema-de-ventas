# Prompts del agente

Aquí se versiona el system prompt del agente de ventas y su changelog, a
partir de la **Fase 4**. La única fuente de verdad en código es
[`lib/agent/prompt.ts`](../../lib/agent/prompt.ts); esta carpeta guarda una
copia legible con el historial de cambios de cada versión (qué cambió y por
qué), útil para revisar reglas duras sin leer TypeScript.
